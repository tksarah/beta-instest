Features

講師の授業中ワークフローに合わせた機能

教材からAIで問題作成

授業内容のテキストをもとに、選択式の小テスト案を生成し、講師が編集して公開できます。

QR・URLで即時配布

クラスとテストを作成したら、生徒はブラウザから参加できます。専用アプリのインストールは不要です。

回答結果をすばやく確認

受験セッション、スコア、正誤、解説を確認し、授業中の理解度チェックに活用できます。

Flow

3

FAQ

よくある質問

生徒もGoogleアカウントが必要ですか？

いいえ。生徒は共有されたURLやQRからブラウザで参加できます。

ベータ版は無料ですか？

はい。現在は無償ベータとして提供します。品質改善のため、ぜひフィードバックをお寄せください。

AI生成は必須ですか？

必須ではありません。講師が手動で問題を作成・編集することもできます。

まずは授業で試して、率直な声を聞かせてください。
